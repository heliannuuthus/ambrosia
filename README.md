<h1 align="center">Ambrosia</h1>

Ambrosia 是 Zwei 背后的后端服务。它管菜谱、标签、收藏、浏览历史和饮食偏好，并据此给用户做场景化的餐食推荐。服务名、OAuth audience 和物理数据库名都是 `ambrosia`。

Ambrosia is the backend behind Zwei: recipes, tags, favorites, viewing history, dietary preferences, and contextual meal recommendations. The service name, OAuth audience, and physical database are all `ambrosia`.
